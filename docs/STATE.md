## What works (verified)

- **Rust `fits` module** (`src-tauri/src/fits/mod.rs`): header parser, HDU
  enumeration, mmap-backed open. Unchanged from M0 except `data()` accessor.
- **Rust `tiles` module** (`src-tauri/src/tiles/`): 256×256 f32 tiles at
  downsample level L = every 2^L-th pixel (block-SAMPLING, matching DS9's
  zoom-out default; averaging is a backlog option). All BITPIX, BSCALE/BZERO,
  BLANK→NaN, edge tiles, first plane of cubes. `zscale.rs` reproduces
  astropy's ZScaleInterval exactly (fixture-tested to 1e-6, incl. NaN
  filtering, sigma-clip iterations, np.convolve mask growth); minmax too.
- **Fixtures extended**: `gen_fixtures.py` adds a NaN block to the primary
  image + `scale_checks` (astropy zscale/minmax) + `tile_checks` (numpy
  strided sampling, level 0 and 1) to `expected.json`. **13 tests green**
  (`cd src-tauri && cargo test`).
- **IPC**: `get_tile` returns binary `tauri::ipc::Response` — [u32 w, u32 h]
  LE + f32 LE pixels; arrives in JS as ArrayBuffer, zero JSON overhead.
  `get_scale_limits(mode: zscale|minmax)` (~200k spatial samples on huge
  images — approximate vs astropy there, exact on small ones),
  `get_pixel` (Option<f64>, None = NaN since JSON can't carry NaN),
  `list_open_files` (frontend recovers state after vite hot-reload).
  Commands are async + `spawn_blocking`; files held as `Arc<FitsFile>` so
  tile extraction runs outside the state lock (parallel requests).
- **Frontend viewer** (`src/render/`): `gl.ts` (WebGL2, R32F NEAREST
  textures — float textures can't filter in core WebGL2; 256×1 RGBA LUT;
  stretch as uniform switch: linear/log/sqrt/squared/asinh/sinh/power with
  DS9's constants), `viewer.ts` (camera, tile LRU ≤600 GPU tiles with
  coarsest-level backdrop never evicted, drag-pan, cursor-anchored wheel
  zoom, double-click/button Fit, readout throttled to one get_pixel in
  flight), `colormaps.gen.ts` (generated by `scripts/gen_colormaps.py` —
  matplotlib LUTs + DS9 heat/cool piecewise ramps; venv now has matplotlib).
- **UI**: Image/Header tabs per HDU; toolbar colormap/stretch/scale-mode
  selects + Fit + limits label; status bar right side = readout
  (FITS 1-based x, y, value). Opening a file auto-selects the first image
  HDU **with data** (JWST i2d empty-primary UX confirmed working).
- **Verified visually on real files (2026-07-04)** via screenshot loop +
  CGEvent input synthesis (see gotchas):
  - Fixture: pattern, NaN block (distinct near-black), −999.25 spot, HDU
    switching, viridis, readout value exact (−58580 = raw×BSCALE+BZERO ✓).
  - CEERS MIRI i2d (63 MB, 10 HDUs): auto-selects SCI, renders correctly;
    zero-valued no-coverage region renders mid-gray (it's real 0.0 data,
    not NaN — correct).
  - PRIMER 5 GiB 41800×32000 mosaic (copied to internal disk): open 6 ms,
    zscale 746 ms, visible tiles ~490 ms concurrent → **first meaningful
    render ≈ 0.8 s cold** (< 1 s target ✓). Deep zoom to level 0 native
    pixels works, NaN coverage dark, readout live. Warm re-render trivial.
- **Perf instrumentation**: `[ds10]` eprintln lines for open/tile/zscale
  timings — keep, they're the benchmark harness for regressions.

## Session gotchas (hard-won, do not relearn)

- **vite hot-reload wipes frontend state** in dev; the backend keeps files
  open, and init() now recovers via `list_open_files`. Editing src-tauri/
  restarts the whole app (argv file re-opens); editing src/ only reloads
  the page (file re-opens via the recovery path).
- **UI automation**: `osascript … click at {x,y}` works for buttons but does
  NOT generate pointermove/wheel. Use the CGEvent JXA helper pattern
  (scratchpad `mouse.js`: move/click/drag/scroll via
  `$.CGEventCreateMouseEvent`/`ScrollWheelEvent` posted to
  `kCGHIDEventTap`) — this drove pan/zoom/readout verification. Screen
  points = retina px / 2. Select popups: click the select, then
  `keystroke "<option text>"` + return (type-select).
- WebKit/ANGLE on this Mac: `isnan()` in GLSL works on R32F samples (NaN
  survives texture fetch) — verified with the fixture NaN block and the
  PRIMER blank coverage.
- `screencapture -R x,y,w,h` crops in screen points — handy for reading
  just the status bar.
- Old M0 gotchas still apply: zoxide cd quirk, `lsof -ti :1420 | xargs
  kill` for stale vite, kill via `pkill -f "tauri dev"; pkill -f
  "target/debug/ds10"`, don't pipe backgrounded output through tail.

## Decisions made during M0/M1 (rationale in CLAUDE.md or code comments)

- Hand-rolled FITS header parsing (revisit for .fz support).
- Node stays at system v18; `[profile.dev.package."*"] opt-level = 2`.
- Tiles block-SAMPLE (not average) — matches DS9 default; averaging parked.
- zscale on huge images runs on a ~200k spatial subsample (limits may differ
  marginally from astropy's full-array answer; exact on small images —
  that's what the fixture pins down).
- Tiles draw only after scale limits arrive (no wrong-stretch flash);
  visible tiles still prefetch during the zscale wait.
- Colormap LUTs are a committed generated file (`colormaps.gen.ts`) — don't
  hand-edit; rerun `scripts/venv/bin/python scripts/gen_colormaps.py`.
